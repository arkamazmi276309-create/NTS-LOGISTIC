Connect Your Firebase Project

This is the first setup screen. The portal is not connected to cloud until you paste your Firebase Web App configuration below and publish the Firestore security rules. Never paste a password or service-account private key here.
Setup steps
1. Open console.firebase.google.com and create a project.
2. In Project settings, add a Web App and copy its Firebase configuration object.
3. In Authentication → Sign-in method, enable Email/Password.
4. Create the Admin and four Wishmaster users in Authentication. Use each user's email and password; do not share passwords in this chat.
5. In Firestore Database, create the database and publish the security rules supplied separately in this setup pack.
6. Create a users document for each account using its Authentication UID. Set role to admin for the owner and wishmaster for the four WM accounts; set wmCode to WM001–WM004 for those users.
